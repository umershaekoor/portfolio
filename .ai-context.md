## Development Patterns

### Component Structure
- Use standalone components (Angular 20)
- Prefer `inject()` over constructor injection
- Keep styles in separate SCSS files
- Mobile and desktop styles separated when needed

### State Management
- Services for shared data (`TranslateService`, `LanguageService`)
- Local component state for UI
- Signals for reactive updates

### Styling
- SCSS with CSS custom properties
- Responsive with media queries
- Mobile-first approach
- Clamp for fluid typography

### Internationalization
- ngx-translate for i18n
- JSON files in `assets/i18n/`
- Language switcher component

## Troubleshooting

### Build Issues
- Check `docs/deployment/DEPLOY_FIXES.md`
- CSS budget exceeded → increase in `project.json`
- Linting errors → run `npm run lint`

### Mobile Issues
- See `docs/history/MOBILE_FIXES_COMPLETE_SUMMARY.md`
- Check responsive breakpoints in SCSS
- Test with browser DevTools mobile view

### Deployment Issues
- Check `docs/deployment/DEPLOYMENT.md`
- Verify nginx config: `ssh contabo-server "sudo nginx -t"`
- Check logs: `ssh contabo-server "sudo journalctl -xeu nginx"`
